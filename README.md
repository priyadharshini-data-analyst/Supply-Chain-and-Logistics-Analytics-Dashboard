# 🚚 Supply Chain & Logistics Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Supply Chain & Logistics Analytics Dashboard** developed using Microsoft Power BI to analyze business performance across suppliers, inventory, shipments, and customers.

The dashboard consolidates key performance indicators (KPIs) and visual insights to help stakeholders understand revenue, profitability, supplier lead times, inventory availability, shipment delays, and customer performance.

The goal of this project is to transform operational data into actionable business insights that support data-driven decision-making.

## 🎯 Business Objectives

- Monitor overall revenue and profitability.
- Evaluate supplier performance using average lead time.
- Analyze inventory levels across products.
- Identify logistics providers associated with shipment delays.
- Compare revenue generated by different customers.
- Track order quantity, inventory quantity, and shipment performance.
- Present important business KPIs in a single interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization.
- **CSV datasets** — Source data for supply chain analysis.
- **Data analysis and KPI reporting** — Business performance monitoring.
